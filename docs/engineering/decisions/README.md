# Architecture Decision Records — Qmenu / Smart Business OS

Create `YYYY-MM-DD-short-title.md` per accepted architectural decision. Record date, project, owner/approver, context, alternatives, selected option, rejected trade-offs, security/tenant/privacy effects, implementation PR/SHA, test evidence and rollback. Mark PROPOSED, ACCEPTED or SUPERSEDED; preserve old decisions and link replacements. Never store secrets or customer/medical data here.
